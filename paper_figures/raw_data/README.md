# Raw data

All current paper-facing data use seed1000 unless explicitly stated.

- Performance, sensitivity, training, mechanism and efficiency CSVs are generated by `scripts/extract_existing_data.py`.
- `PROVENANCE.csv` maps every extracted dataset to branch/commit/path/key.
- CoLiftRec seed1000 modality ablation: `OPTIONAL_DATA_NOT_YET_FROZEN`.
- Case study: `OPTIONAL_DATA_NOT_YET_FROZEN`.
- Fig15/16 rank-band data are produced only by deterministic TRAIN-side diagnostic replay if historical per-band evidence is unavailable.
