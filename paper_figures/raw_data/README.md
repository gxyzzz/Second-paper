# Raw data

All current paper-facing data use seed1000 unless explicitly stated.

- Performance, sensitivity, training, mechanism and efficiency CSVs are generated by `scripts/extract_existing_data.py`.
- `PROVENANCE.csv` maps every extracted dataset to branch/commit/path/key.
- CoLiftRec seed1000 modality ablation: Baby 的固定 B0 checkpoint Validation T/A/V 组合已采集；Sports/Electronics 尚未补采。
- Case study: `OPTIONAL_DATA_NOT_YET_FROZEN`.
- Fig15/16 rank-band data are produced only by deterministic TRAIN-side diagnostic replay if historical per-band evidence is unavailable.
- The new content-preference probe is CPU-only and uses raw Text/Visual features and TRAIN rows only, with 2,000 deterministically sampled Baby users. Its CSV/JSON and provenance use `seed=N/A` for model seed; 20261013 is the sampling seed. It is not a formal recommendation benchmark.
- Historical CSVs retain their extraction IDs. Final plot IDs are mapped in `../VISUAL_REDESIGN_PLAN.md`; filenames do not imply that similarly numbered data and figures have identical contents.
- 新增逐事件 PDBR 数据：`mechanism/fig15_16_sample_diagnostics.csv`，4,096 个随机排序的 TRAIN 事件 × 三分带；CPU 新噪声流、无权重更新、不作 CUDA 逐样本 parity 声明。
- 新增全体 Baby Validation 相关物品排名转移：`performance/fig17_validation_rank_transitions.csv`；101 表示 >100 的删失标记，不是精确排名。
- 新增 CoLift 模态消融：`performance/fig18_colift_modality_ablation.csv`；全部八种设置用同一个冻结 B0 checkpoint、Top100、TRAIN 背景与原权重。
- 采集协议、冻结来源及 CPU Validation parity 在 `mechanism/ADVANCED_DIAGNOSTICS_PROTOCOL.json`；没有新增 Test 评估。
