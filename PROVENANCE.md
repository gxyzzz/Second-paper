## Server compatibility note

The frozen upstream source was authored for Python 3.8.10, PyTorch 1.11.0+cu113, and NumPy 1.21.5. The current RTX 5090 server smoke uses the existing msca environment (Python 3.9.25, PyTorch 2.7.0+cu128, NumPy 2.0.2). NumPy 2.x removes the deprecated np.float alias, so src/utils/metrics.py carries only the semantics-preserving np.float -> builtin float compatibility patch already validated in the historical server workspace. No scientific formula or metric definition is changed.
