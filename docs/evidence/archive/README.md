# Archived Research Evidence

This directory preserves development, robustness, migration, and legacy-replay evidence for traceability.

Publication-facing evidence is intentionally limited to ../final/.
Archived JSON files are historical records and are moved without changing their scientific contents.

- development/: intermediate training, validation, diagnostics, and frozen-run records.
- robustness/: dedicated robustness studies, including the Baby multiseed experiment.
- legacy_replay/: exact legacy scoring replay evidence.
- migration/: repository/code migration parity evidence.

Formal runtime code under src/ and scripts/ does not depend on this archive.
